**Overview:**

Rotor Rush is a small arcade-style game written in Lua for EdgeTX transmitters like the RadioMaster TX16S. It runs as a Tools script and is designed to be played between flights directly on the radio.
Fly your helicopter across a scrolling landscape while avoiding planes, drones, mountains, and trees. Collect yellow circles to score points. Every 10 points increases the game speed, making it progressively harder.

**Controls:**
- CH3 – Move helicopter up / down
- CH2 – Move helicopter left / right
- ENTER – Start / Restart game

**Features:**
- Scrolling environment
- Random planes and drones
- Collectible points
- Increasing difficulty
- Arcade-style sound effects
- Change Helicopter color using SC switch (Black / Red / Pink)
- Splash screen and flashing Game Over 

**Installation:**
- Copy RotorRush.lua to /SCRIPTS/TOOLS
- Copy RotorRush.png to /IMAGES/
- Copy rrmus.wav to /SOUNDS/en
- Add a Global Function with a switch to turn the game music on/off.
