# Stork 🥚🟩🟦 Telor Asin

The Blue-greenish theme from that salted duck egg.

## Installation

It's easy!

- Put this `Stork_TelorAsin` folder into your EdgeTX SDCard at `THEMES/`. You have seen this sample SD Card we got here, now go place it as this one does
- On Main screen, press `SYS` top left
- `PAGE >` repeatedly until you go to `🎨 Themes selection` tab. Or click `🎨 Themes selection` tab.
- Scroll down or Jogwheel down and choose `Stork_TENS` theme.
- `ENTER` (Jogwheel press) & `Set Active`.
- Enjoy!
